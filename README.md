# 📈 ICT Backtester Pro

![Python Version](https://img.shields.io/badge/python-3.9%2B-blue)
![Architecture](https://img.shields.io/badge/architecture-Event--Driven-orange)
![License](https://img.shields.io/badge/license-MIT-green)

**ICT Backtester Pro** is a production-grade, event-driven algorithmic backtesting engine built in Python. Designed strictly without lookahead bias, it programmatically detects "Inner Circle Trader" (ICT) price action concepts such as Break of Structure (BOS), Change of Character (CHoCH), and Fair Value Gaps (FVG). 

The engine realistically simulates trade execution complete with spread, slippage, strict position sizing, and daily circuit breakers, concluding with interactive Monte Carlo performance statistics and gorgeous HTML visual reports.

---

## ⚡ Key Features

- **Strict Event-Driven Architecture:** Decoupled `EventBus` architecture ensures data flows chronologically. 100% guarantee against lookahead bias.
- **Algorithmic ICT Pattern Detection:** Purely functional, mathematically strictly defined rules to identify Swing Points, BOS, CHoCH, and track Unmitigated/Mitigated FVGs.
- **Dynamic Position Sizing & Risk Management:** Automated fractional risk (e.g., 1% per trade) utilizing dynamic lot sizing adjusted per asset class (Forex vs. Metals). Includes daily drawdown circuit breakers.
- **Stunning Interactive Reporting:** Generates a fully interactive standalone HTML dashboard via Plotly. Features toggleable pattern overlays on price charts, underwater drawdown charts, and monthly heatmaps.
- **Monte Carlo Analytics:** Built-in 10,000-iteration Monte Carlo engine projecting probabilities of ruin and extreme drawdowns.
- **Institutional Cost Modeling:** Factors in raw spread expansion, broker commission ($/lot), and simulated execution slippage.

## 💻 Usage

Run the engine natively from the terminal using the `Typer` CLI. The CLI handles data downloading, event walking, pattern scanning, and report generation in a single command.

### Basic Run
Run using the default configurations defined in `config/default.yaml`:
```bash
python main.py
```

### CLI Overrides
You can dynamically override the configuration file without touching the YAML:
```bash
# Test a specific forex pair
python main.py --symbol EURUSD=X

# Test a specific date range
python main.py --symbol GC=F --start 2025-01-01 --end 2025-06-01
```

## ⚙️ Configuration (`config/default.yaml`)

Control risk exposure, session times, and pattern rules via the YAML config:

```yaml
instrument:
  symbol: "XAUUSD=X"
  display_name: "XAUUSD"

timeframe: "1H"
date_range:
  start: "2025-01-01"
  end: "2026-01-01"

risk:
  risk_per_trade: 0.01  # 1% of equity per trade
  rr_ratio: 2.0         # Reward-to-Risk ratio
  max_daily_risk: 0.03  # Halt trading if daily loss hits 3%

execution:
  spread_pips: 2.0      
  slippage_pips: 0.5
  commission_per_lot: 7.0

sessions:
  asian: "20:00-00:00"
  london: "03:00-11:00"
  ny: "08:00-17:00"
```

## 🏗️ Architecture Overview

The system is highly decoupled:
1. **`data_loader.py`**: Pulls and caches OHLCV data using `yfinance` and PyArrow. Tags candles strictly by ICT Sessions (London, NY, Asian).
2. **`pattern_detector.py`**: A purely functional, state-tracking scanner listening to the `EventBus` to discover complex topological structures dynamically.
3. **`backtest_engine.py`**: Listens for `PatternEvent` to queue limit/stop orders, and `CandleEvent` to simulate fills against high/low price boundaries. 
4. **`statistics.py` & `visualizer.py`**: Aggregates the resulting `TradeResult` objects, extracting R-multiples, Sharpe ratios, expectancy metrics, and compiling them into the visual `.html` report.

---

## 📊 Outputs

All simulation outputs are exported directly to the `/reports` directory:
- **`ict_backtest_report_*.html`**: The interactive charting dashboard. Open this in your browser to inspect entry/exit plots, FVG shading, and performance metrics.
- **`report.json`**: Contains serialized JSON metadata of all statistical arrays generated by the Monte Carlo and session-breakdown logic for programmatic use.
